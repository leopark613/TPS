# 문서 저장 A7 스키마

001_TPS_DOC_A7.sql은 검토된 실제 A7 생성 스크립트의 사본이다. 원본 파일 첫 주석의 draft/not-executed 표현은 작성 당시 이력이며, 지정 로컬 TPS DB 준비 때 실제 적용/검증됐다. 이미 테이블이 있으면 중단하도록 작성되어 있다. 제품 시작이나 빌드에서 자동 실행하지 않는다.
현재 로컬 TPS에는 이7개와 기존RPS12개/272행복사본이 있다. 기존 데이터 복사·MES_LITE 구조정렬 SQL·실행 결과는 TPS 기록 정본에 보관되어 있으며, 전체1차 완료 후 최종 인계 패키지에 함께 수집한다. 이 파일만으로 기존RPS 데이터나 전체TPS 기능DB가 재현되는 것은 아니다.
