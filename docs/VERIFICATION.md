일반 보고서 한 행 데이터 연결·QR·저장본 미리보기 단위를 구현하고 검증했다. 전체 TPS의 완료는 아니다.

선택 행의 text/QR 해석, 정확한 immutable revision, 이전 버전 재현, unknown query 버전/임의 SQL 입력/다른 site/비활성 RPS/LPS 소유 차단, QR 빈 값·용량 초과·미지원 속성의 정확한 오류를 확인했다. 생성 matrix의 판독 외에 **실제 브라우저 SVG 픽셀을 캡처해 QR를 다시 판독**하여 선택 값과 한글·선행0·줄바꿈 원문이 일치하는지 검사했다. 업무 데이터가 들어간 임시 QR 이미지는 즉시 제거했고, 남긴 화면은 합성 입력뿐이다.

기존 RPS12의 값·구조·identity, 다른 site의 문서 행, 모든 사용자 테이블의 컬럼·인덱스·제약·트리거 구조 해시가 전후 일치했다. 시험 site/추적ID의 문서만 저장했고 각 시험 후 정확히 정리했다. 새 테이블과 업무 활성화 변경은 없다. 프린터 송신 기능은 이번 구현에 포함하지 않는다.

초기 실패도 보존했다. 새 실제 브라우저 시험의 체크 함수 호출에서 인수가 하나 빠져 TypeError가 발생했다. 당시 생성한 시험행 정리 후 시험 도구를 수정했고 최종16개가 통과했다. 제품의 저장/QR 오류로 숨기거나 실패 증거를 삭제하지 않았다. 단위 시험의 canonical 숫자 노드 비교 보정 및 독립 검토에서 발견된 QR 용량·편집 가능 판정·폰트 범위 차이도 수정했다.

현재 Eclipse4.33/m2e2.6.1의 JAR 플러그인 호환 문제에는 m2e에서만3.4.2를 쓰고 일반CLI는3.5.1을 유지한다. frontend/dist는 copy-resources로 반영한다. POM XSD는 공식 원본을 로컬에 포함해 외부 XML 다운로드를 켜지 않고 해결했다. 실제 GUI에서 오류0개/경고6개를 확인했다. 사용자는 기동을 막지 않는 경고를 더 조사하지 않도록 지시했다. Spring Tools 외부 버전 정보 PKIX 팝업은 별도 사내 인증서 신뢰 문제이며 TLS 검증/인증서 저장소/전체 Java 검증 설정은 바꾸지 않았다.

실제 Eclipse Run/Debug는 사용자가 다음 실행 안내에 따라 확인할 단계다. CLI 실행·실제 DB/웹 검증과 이를 구분한다. Excel·업무 SQL 관리·PDF/반복/페이지 분할·LPS 채번·물리 프린팅·운영 인증·최종 배포/성능 비교는 후속이다. GitHub push, 최종 PDF, 전체 참조 인계 패키지는 아직 실행하지 않았다.

## TPS-IMPL-001 이전 단위의 검증 이력

2026-11-06. **양식 저장·재열기 첫 구현 단위 통과. 전체 TPS 완료가 아니다.**

| 검증 | 실제 결과 |
|---|---|
| Maven Java 단위 시험 | 36/36, 실패·skip 0 |
| Gradle Java 단위 시험 | 같은 36/36, 실패·skip 0 |
| React 상태·기능 판정 시험 | 15/15 |
| 실제 SQL Server API 시험 | Maven 실행 43/43 |
| 포함 Java 런타임 + Gradle JAR | 실제 DB API 43/43 |
| 실제 React → Boot → SQL 브라우저 | 14개 검사 통과 |
| 모의 API 지연·충돌 브라우저 | 11개 항목 통과, DB 쓰기 없음 |
| 산출물 비교 | 런타임 라이브러리 56개와 애플리케이션 항목 36개의 내용이 동일 |
| 독립 검토 | 지적 3개 수정·재검토 완료, 추가 차단 결함 없음 |

실제 DB 시험은 고유 `TPS_IT_` 사이트에서 수행했다. 저장/수정/재열기/이전 버전, 같은 요청의 순차·동시 재시도, 서로 다른 동시 저장의 단일 성공, stale 충돌, 검증 실패 시 행 불변, 모듈 제한, 새 JVM의 재열기를 포함한다. 시험 후 추적한 ID와 소유·관계를 확인하고 해당 행만 트랜잭션으로 정리했다. 원래 RPS12 데이터·구조·identity 및 다른 사이트 해시는 유지됐다.

실제 브라우저는 텍스트·사각형 편집, 두 저장 버전, 이전 버전 읽기 전용, 새 브라우저 재열기, RPS/LPS 목록 구분, 모바일 폭, JS 예외 없음, JVM 재시작 후 복원을 확인했다. 화면의 정밀 인쇄 결과나 실제 프린터 출력 시험은 아니다.

초기 실패도 기록했다. SQL 관찰 도구의 컬럼 수 오류, 브라우저 시험의 미저장 전환 확인/비동기 목록 대기 누락은 도구·시나리오를 수정한 후 통과했다. 독립 검토의 Nexus 게시 대상 제한, 로딩 중 복사 경합, 기능 지원 판정 불일치는 제품/설정을 수정하고 회귀 검사했다.

Windows의 AF_UNIX selector 연결 오류에는 해당 실행 프로세스의 `jdk.net.unixdomain.tmpdir`을 이용한 JDK TCP 루프백 대체 경로를 검증했다. 전역 보안·방화벽 설정은 바꾸지 않았으며 다른 PC의 필수 기본값으로 간주하지 않는다. Eclipse4.33/JDK21/m2e 및 Lombok1.18.48 설치 준비를 확인했지만 **Eclipse GUI import·Run/Debug는 아직 검증하지 않았다.**

실제 Jenkins/Nexus 연결·게시, GitHub push, 타인 PC 설치·출력, RPS/TPS 성능 비교, 전체 인계 패키지와 최종 PDF는 후속이다. 자세한 실행 증거와 실패 이력은 사용자 TPS 기록 정본의 `verification/TPS-IMPL-001`에 보관한다.
